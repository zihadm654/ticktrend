# Conversion map

Vocabulary the codebase must use after the conversion.

| Perfume | Watch |
| --- | --- |
| Fragrance / perfume | Watch |
| Fragrance house / brand type designer, niche, arabian, celebrity | Watch house / imported, mastercopy, firstcopy, local |
| Concentration (EDT, EDP, parfum, oil, attar) | Movement (quartz, automatic, mechanical, solar, digital, smart) |
| Fragrance family | Style (dress, sport, casual, digital) |
| Perfumer | Reference number / collection |
| Scent notes + top/heart/base | Features + feature group |
| Bottle size in ml | Dial/strap option |
| Packaging (tester, sample, mini, gift set) | Condition (new, open box, refurbished, used) |
| Size buckets under 50 / 50–99 / 100+ ml | Case-size buckets <36 / 36–40 / 41–44 / 45+ mm |
| Scent pyramid | Grouped feature chips |
| "About this fragrance" | "About this watch" |
| "Browse fragrances" | "Browse watches" |

Watch specifications that have no perfume predecessor: case size, case material, strap type, glass, water resistance, dial colour, warranty months.

Watch-specific trust content: authenticity, warranty, box and papers, water-resistance guidance.
